## 1. Hypercare duration and scope

The hypercare period covers **28 calendar days** post-production go-live. Scope includes:

- SAP application and HANA DB stability
- Azure infrastructure (VMs, ANF, ExpressRoute, Pacemaker)
- Azure management services (ACSS, Monitor for SAP, Backup)
- SAP Fiori SSO via Microsoft Entra ID

---

## 2. Support model

| Priority | Response time     | Resolution target | Examples                                      |
| -------- | ----------------- | ----------------- | --------------------------------------------- |
| P1       | 1 hour            | 4 hours           | System down, HANA crash, data corruption risk |
| P2       | 4 hours           | 1 business day    | Performance degradation > 30%, backup failure |
| P3       | Next business day | 5 business days   | Minor UI issues, non-critical alerts          |

### Escalation path

1. **L1:** Customer's Azure/SAP Basis team (trained during KT)
2. **L2:** Contoso SAP Practice on-call engineer
3. **L3:** Azure SAP FastTrack (P1/P2 only)
4. **L4:** SAP Support (application-level issues)

## 4. Daily monitoring checklist (weeks 1–2)

Run daily during weeks 1 and 2; move to weekly in weeks 3–4.

- [ ] ACSS VIS dashboard: all components show **Healthy**
- [ ] Azure Monitor for SAP: HANA CPU < 70% avg, memory < 85%
- [ ] HSR replication lag: ≤ 30 s (`systemreplicationstatus.py`)
- [ ] Azure Backup: last full backup status = **Completed**; log backup within last 20 min
- [ ] Pacemaker cluster: `crm_mon -1` shows no failed resources
- [ ] No open P1/P2 tickets

---

## 5. Exit criteria

Hypercare closes when **all** the following are met:

| Criterion                                   | Target                            |
| ------------------------------------------- | --------------------------------- |
| P1 incidents in final 7 days                | 0                                 |
| P2 incidents in final 7 days                | 0                                 |
| Azure Backup success rate (last 14 days)    | 100%                              |
| HANA HSR replication lag (last 14 days avg) | ≤ 15 s                            |
| Customer self-service on ACSS + Monitor     | Confirmed by customer IT lead     |
| KT sign-off received                        | Signed KT completion form on file |

---

## 6. Hypercare closeout report

On exit-criteria completion, the partner delivers a **Hypercare Closeout Report** containing:

1. Summary of all P1/P2/P3 incidents and resolutions
2. Azure Monitor for SAP performance baselines (CPU, memory, IOPS, HANA p99)
3. Backup success rate summary
4. Outstanding items (P3 or cosmetic) handed to steady-state support
5. Customer sign-off signature
