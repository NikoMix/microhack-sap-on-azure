### Go criteria (all must be ✅)

- SAP logon works for test user on new primary
- SM21 shows no critical errors in last 15 min
- HSR replication lag ≤ 30 s
- Azure Monitor for SAP dashboard shows green

### No-go / rollback triggers

If any go criterion fails at T+4h (02:00 UTC), execute rollback:

1. Stop SAP on new primary
2. Re-promote original primary via HSR takeover
3. Restart SAP on original primary
4. Reset DNS TTL to 300 s
5. Notify customer; reschedule cutover window
