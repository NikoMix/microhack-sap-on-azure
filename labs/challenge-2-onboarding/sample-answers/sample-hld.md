## 1. Solution overview

This HLD describes the target architecture for a SAP S/4HANA 2023 greenfield deployment on
Microsoft Azure for ACME Manufacturing. The solution delivers a highly available, zone-redundant
SAP landscape with integrated Azure management services (ACSS, Azure Monitor for SAP, Azure
Backup).

### 2.4 High availability and disaster recovery

| Failure domain    | Protection mechanism                      | RTO     | RPO       |
| ----------------- | ----------------------------------------- | ------- | --------- |
| HANA DB VM        | HSR sync → automatic failover (Pacemaker) | < 30 s  | ≈ 0       |
| ASCS/ERS          | Pacemaker + SBD floating IP failover      | < 30 s  | N/A (app) |
| Zone outage       | Zone-redundant deployment (AZ 1 + AZ 2)   | < 5 min | ≈ 0       |
| Accidental delete | Azure Backup (Backint) — full + log daily | < 4 h   | 15 min    |

### 2.5 Management services

- **ACSS (Azure Center for SAP Solutions):** VIS registration, HANA health insights, guided operations
- **Azure Monitor for SAP Solutions:** HANA DB, OS, NetWeaver, Pacemaker metrics + alerting
- **Azure Backup for SAP HANA:** Backint-certified daily full + 15-min log backups to RSV

## 3. Security and identity

- Microsoft Entra ID for all Azure RBAC and SAP Fiori SSO (SAML 2.0)
- PIM (Privileged Identity Management) for SAP Basis elevation (just-in-time)
- Azure Firewall Premium with TLS inspection for SAP GUI / RFC traffic
- Private Endpoints for ANF; no public IPs on SAP VMs
