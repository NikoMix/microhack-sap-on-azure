## Challenge

ACME Manufacturing required a replacement for their legacy SAP ECC 6.0 on-premises system. Key
requirements:

- Zero-downtime migration path (HSR-based cutover)
- HANA DB latency ≤ 2 s p99 for MRP run
- Full HA/DR in a single Azure region using Availability Zones
- Managed backups aligned to 15-minute RPO
- SAP Fiori SSO via Microsoft Entra ID (SAML 2.0)

## Azure Solution Architecture

| Layer      | Azure service / SKU                                                        |
| ---------- | -------------------------------------------------------------------------- |
| Compute    | SAP HANA: Standard_M208ms_v2 × 2 (HSR, AZ1 + AZ2)                          |
|            | SAP App servers: Standard_E32ds_v5 × 2                                     |
|            | ASCS/ERS: Standard_D4s_v5 × 2 (Pacemaker + SBD across zones)               |
| Storage    | Azure NetApp Files — Ultra tier (4 TB, `/sapmnt`, `/usr/trans`, HANA vols) |
| Networking | Azure ExpressRoute (2 × 1 Gbps circuits, active/active) + Azure Firewall   |
| HA / DR    | Availability Zones 1 & 2; HSR sync replication; Pacemaker + Azure Fence    |
| Management | ACSS VIS registration; Azure Monitor for SAP; Azure Backup (Backint) daily |
| Identity   | Microsoft Entra ID (SAML SSO for Fiori), PIM for Basis elevation           |
