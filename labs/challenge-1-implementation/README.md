# C1 · B.1.1 — SAP on Azure Implementation Capability

**Control:** B.1.1 — SAP on Azure Implementation Capability  
**Module B Specialization:** SAP on Microsoft Azure Advanced Specialization  
**Estimated time:** ~75 minutes

> The full click-by-click lab is on the course site at **[C1 · B.1.1 Implementation Capability](/modules/b11-implementation/)**.  
> This README is the quick-start reference + verification you run in the terminal.

---

## Objective

Produce the three **B.1.1 evidence artefacts** a specialization auditor will check:

1. **Case study** — anonymised customer engagement with measurable outcomes
2. **Architecture diagram** — Mermaid/PDF showing the SAP-on-Azure service topology
3. **Capability statement** — partner-authored narrative mapping the practice to B.1.1

All three are generated with the **Module B Lab Coach** Copilot agent + `draft-case-study` skill,
then filed using the `[ControlRef]_[DocumentType]_v[N].pdf` convention.

---

## Prerequisites

- C0 complete: Codespace running, `az account show` prints your subscription, Copilot agent loaded.
- `az bicep version` returns a Bicep CLI version (run `az bicep install` if missing).

---

## Quick steps

```bash
# 1. Confirm Azure login
az account show -o table

# 2. Compile-check the Bicep landing zone
az bicep build --file infra/main.bicep

# 3. (Optional) Dry-run deployment
az deployment sub what-if \
  --location swedencentral \
  --template-file infra/main.bicep \
  --parameters infra/params/lab.bicepparam
```

Then open Copilot Chat and run the prompts from the lab page (Steps 4–6):

- `@moduleb-lab-coach #draft-case-study` → case study
- Architecture diagram prompt → Mermaid block
- Capability statement prompt → narrative doc

## Verification

Run the verification script:

```bash
# Bash (Linux / macOS / Codespaces)
bash labs/challenge-1-implementation/verify.sh

# PowerShell (Windows or any platform)
pwsh labs/challenge-1-implementation/verify.ps1
```

### What the script checks

| Check                        | Pass condition                                      |
| ---------------------------- | --------------------------------------------------- |
| Bicep compile                | `az bicep build --file infra/main.bicep` exits 0    |
| Evidence folder exists       | `Module B/B1.1/` directory present                  |
| Case study present           | `Module B/B1.1/B11_CaseStudy_v1.*` exists           |
| Architecture diagram present | `Module B/B1.1/B11_ArchitectureDiagram_v1.*` exists |
| Capability statement present | `Module B/B1.1/B11_CapabilityStatement_v1.*` exists |

---

## Definition of done

- [ ] `az bicep build --file infra/main.bicep` exits 0
- [ ] `az deployment sub what-if` completed (optional but recommended)
- [ ] Three evidence files created and named `B11_*_v1.*`
- [ ] Case study includes at least one measurable outcome (latency, RTO, downtime)
- [ ] Architecture diagram includes both Availability Zones and all key services
- [ ] Capability statement is ≤ 500 words, formal, third-person
