## Learning objectives

By the end of this lab a trainee can:

- Compare the two B.3.1 routes — **AZ-120** certification vs the **Run SAP on the Microsoft Cloud**
  learning path — and choose the fastest gate for this cycle.
- Use a Copilot skill to generate a **skilling mapping table** (Name → route → completion → expiry)
  and a personal study plan from the Microsoft Learn modules.

## Lab outline

<Steps>
  1. Review the two skilling routes and evidence requirements. 2. Generate the skilling mapping
  table with the `build-skilling-plan` skill. 3. Produce a per-person Microsoft Learn study plan.
</Steps>
