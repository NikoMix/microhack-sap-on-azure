## Learning objectives

By the end of this lab a trainee can:

- Use the **Azure MCP server** (Cost Management / consumption) from GitHub Copilot to pull the
  trailing-3-month consumption for a subscription.
- Identify and tag the **SAP-on-Azure-eligible** service set (M/Mv3, ANF, Premium SSD v2, ExpressRoute,
  ACSS, Monitor for SAP) and produce an **annotated breakdown** + **trend chart**.
- Explain and demonstrate **PAL** setup as the fastest fix for under-attributed ACR.

## Lab outline

<Steps>
  1. Connect Copilot to the Azure MCP server (configured in the devcontainer). 2. Query consumption;
  export the By-Service and By-Customer views (sample data provided). 3. Use the `annotate-acr`
  skill to isolate SAP-eligible spend and build the trend. 4. Walk the PAL setup steps on a
  subscription.
</Steps>
