## Learning objectives

By the end of this lab a trainee can:

- Map **SAP Activate** phases to the **Azure migration workstream**.
- Register the simulated landscape with **Azure Center for SAP solutions (ACSS)** and enable
  **Azure Monitor for SAP solutions** and **Azure Backup for SAP HANA** (guided portal + CLI).
- Use Copilot skills to generate a repeatable **onboarding pack**: HLD, LLD, runbook, KT plan and
  hypercare plan, then show evidence of application to one customer.

## Lab outline

<Steps>
  1. Walk the SAP Activate → Azure mapping. 2. Register/representation in ACSS; enable Monitor for
  SAP + Backup. 3. Generate the onboarding deliverables with the `generate-hld` / `generate-runbook`
  skills. 4. Produce an anonymised "evidence of application" cover artefact.
</Steps>
