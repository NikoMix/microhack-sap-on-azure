## Learning objectives

By the end of this lab a trainee can:

- Build the **evidence folder structure** (`Module B / B[ref] /`) and an **evidence index** with one
  row per control.
- Run an **internal pre-audit review** and appoint a single point of contact.
- Use a Copilot skill to validate that every artefact from C1–C5 follows the
  `[ControlRef]_[DocumentType]_v[N]` convention and that no control is missing evidence.

## Lab outline

<Steps>
  1. Generate the evidence index + folder structure with the `build-evidence-index` skill. 2.
  Collect the C1–C5 artefacts into the structure. 3. Run the Copilot completeness/naming validation
  and fix gaps. 4. Capture the pre-audit review record + SPOC.
</Steps>
