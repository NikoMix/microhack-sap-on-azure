## Reference service set

| Layer      | Azure services                                                                                           |
| ---------- | -------------------------------------------------------------------------------------------------------- |
| Compute    | M-series, Mv2-series, **Mv3-series** (HANA); Edsv5 / Dsv5 (app tier)                                     |
| Storage    | **Azure NetApp Files**, Premium SSD v2, Ultra Disk, Azure Files Premium                                  |
| Resilience | **Availability Zones**, HSR (sync/async), ASCS/ERS (Pacemaker + SBD), Azure Site Recovery                |
| Network    | **ExpressRoute**, Global Reach, Azure Firewall, Private Endpoints                                        |
| Management | **ACSS**, Azure Monitor for SAP solutions, Azure Backup for SAP HANA, Azure Update Manager               |
| Identity   | Microsoft Entra ID (SAML for Fiori SSO), PIM for Basis elevation                                         |
| Automation | SAP on Azure deployment automation framework (Terraform + Ansible); this repo uses Bicep/AVM for the lab |
