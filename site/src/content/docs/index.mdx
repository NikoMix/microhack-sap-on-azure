## A one-day, hands-on path through Module B

This microhack is built **Train-the-Trainer**: you'll learn it by doing the labs, and leave able to
**re-deliver** it to your own team. It targets **SAP consultants who are newer to Azure**, so every
lab includes generous Azure scaffolding — guided portal clicks _and_ CLI — with **GitHub Copilot**
custom agents, skills and MCP servers acting as your in-lab coach.

<Aside type="tip" title="You will need">
  A **GitHub account** and an **Azure subscription with Owner** rights. Everything else runs in
  **GitHub Codespaces** — no local installs required.
</Aside>
